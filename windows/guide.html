Instalação e requisitos

O instalador prepara uma cópia do programa na pasta escolhida e baixa as dependências pelo npm. O banco de dados é criado localmente na primeira inicialização. Não é necessário trazer a pasta do computador de quem desenvolveu o aplicativo.

  1. Execute JobTracker-Setup.exe e escolha uma pasta exclusiva pelo botão Escolher.... Use uma pasta em que seu usuário tenha permissão de escrita.
  2. Clique em Baixar e instalar. A janela fica compacta e mostra somente o andamento. Node.js, Visual C++ x64 e WebView2 são conferidos; apenas os ausentes são preparados automaticamente pelo WinGet. PostgreSQL já está incluído; o Windows pode pedir permissão de administrador.
  3. Após concluir com sucesso, o instalador fecha automaticamente. Em caso de erro, a pasta e Tentar novamente reaparecem, e Mostrar detalhes abre os registros. Se um requisito pedir reinicialização, reinicie por sua conta e execute novamente o instalador, escolhendo a mesma pasta. Não há reinicialização automática.
  4. Abra o atalho Job Tracker na área de trabalho. Os registros aparecem desde o início, junto aos estados Iniciando API e Iniciando interface. Quando os serviços estiverem prontos, o aplicativo abre no navegador padrão, com o título JOB TRACKER e o ícone JT. Mantenha o painel aberto enquanto usar o aplicativo. Parar serviços interrompe a inicialização ou encerra os serviços e o banco desta instalação; após confirmar a parada, o painel fecha. Nenhuma nova janela deve abrir durante o encerramento.

A pasta sugerida é %LOCALAPPDATA%\JobTracker\app. As telas usam um servidor local, aberto no navegador padrão. Fechar o painel encerra seus serviços e o banco privado. Abra novamente o atalho para retomar após uma parada manual. Durante a inicialização, a parada aguarda a etapa atual terminar para proteger o banco.

A preparação automática usa o WinGet para Node.js, Visual C++ x64 e Microsoft Edge WebView2 Runtime. Links manuais: Node.js, Visual C++ x64 e WebView2 Runtime. Se necessário, atualize o Instalador de Aplicativo da Microsoft Store.

A barra acompanha o progresso geral por etapas. A conferência e extração dos arquivos usam a quantidade de bytes processados. Durante downloads sem percentual fornecido, a barra mostra atividade e mantém o percentual das etapas já concluídas. Os 100% só aparecem após a preparação terminar com sucesso.

Consulte a licença do Node.js, os termos da Microsoft e a licença do PostgreSQL. Ao clicar em instalar, a preparação automática aceita os termos dos pacotes ausentes e da fonte WinGet.

Novas instalações Windows x64 usam PostgreSQL 16 privado, sem Docker, WSL ou virtualização. Os dados ficam separados dos executáveis e usam senha exclusiva. Instalações antigas que usavam Docker mantêm sua configuração: não são convertidas automaticamente nem substituídas por um banco vazio.

Em caminhos com acentos, o banco usa o alias curto da mesma pasta fornecido pelo Windows. Se o volume não oferecer esse alias, escolha uma pasta sem acentos. Os dados não são movidos para outro local.

Crie seu próprio perfil

  1. No primeiro acesso, crie um perfil. A instalação não inclui currículo, conta Google, candidaturas ou credenciais de outra pessoa.
  2. Em Currículo, informe sua experiência, contatos e localização. Salve as alterações.
  3. Em Preenchimento de candidaturas, configure os dados que deseja reutilizar: nome completo, CPF, país, cidade, última remuneração, expectativa salarial e links profissionais.
  4. Em PDF para candidaturas, use Guardar e ler PDF para guardar o anexo e preencher os campos vazios com os dados reconhecidos. Para um arquivo já anexado, use Ler PDF salvo. A leitura é local, sem API de IA; revise os dados e clique em Salvar. Informações já preenchidas são mantidas. PDFs protegidos ou digitalizados como imagem podem exigir preenchimento manual.
  5. Informe dados de autodeclaração apenas se quiser utilizá-los; a leitura do PDF não deduz esses dados, salários ou outras respostas ausentes.
  6. Em Vagas, ajuste cargo, modalidade, localização e fontes. Faça a busca, confira a descrição e salve as vagas de interesse.

A chave de IA é opcional para organizar candidaturas, buscar vagas e preencher dados já cadastrados.

Instale a extensão no perfil certo

Cada instalação gera sua pasta da extensão na própria máquina, sem carregar dados do desenvolvedor. O código e a versão são iguais para todos; currículo e credenciais vêm somente da instalação local em uso.

  1. No painel, clique em Gerar extensão. A primeira instalação também faz isso automaticamente.
  2. Abra chrome://extensions no perfil Chrome em que você se candidata.
  3. Ative Modo do desenvolvedor e escolha Carregar sem compactação.
  4. Selecione a subpasta job-tracker-chrome-VERSÃO, dentro de dist\chrome da instalação. Ela contém manifest.json.
  5. No programa, clique em Preencher formulário na vaga. A candidatura abre no Chrome com sua extensão e sessão habituais. Permita o acesso HTTPS solicitado. Se usa vários perfis do Chrome, abra o desejado antes da candidatura.

Mantenha a pasta gerada no disco. O ZIP precisa ser extraído antes de carregar. Para atualizar na mesma pasta, clique em Recarregar no Chrome. Se a versão gerar uma pasta nova, remova a extensão antiga e carregue a nova. Cada perfil do Chrome exige sua própria instalação manual.

Referência: instalar uma extensão local no Chrome.

Configure sua API de IA

O provedor atualmente integrado é a Anthropic / Claude API. Uma assinatura de aplicativo não substitui automaticamente a configuração de cobrança da API. Consulte sua conta e seus limites antes de usar.

  1. Acesse sua conta na plataforma Claude, página de chaves. Configure a cobrança da API e crie sua própria chave.
  2. No programa, abra Opções → Configurar API de IA.
  3. Cole a chave e clique em Salvar chave. O campo é mascarado; a chave é protegida com DPAPI para seu usuário Windows e não aparece no guia, no ZIP da extensão ou nos registros da operação.
  4. Clique em Parar serviços e depois em Iniciar para aplicar a configuração.
  5. Solicite uma resposta por IA no aplicativo. A primeira geração confere a chave e a disponibilidade do modelo. Salvar a chave não faz uma chamada paga de teste.

Para desativar, use Remover chave no mesmo diálogo e reinicie. Se você também configurou uma chave manualmente em recruiter-backend\.env, ela precisa ser removida desse arquivo.

Não compartilhe sua chave nem envie capturas de tela contendo credenciais. A proteção do Windows não protege contra um programa malicioso executando como o mesmo usuário.

Referência: como obter sua chave Claude API.

Ative a apresentação personalizada

  1. Preencha o resumo e a trajetória profissional no currículo.
  2. Em Apresentação para empresas, escreva uma apresentação-base, se desejar. Ative Personalizar e preencher a apresentação para cada empresa e salve.
  3. Use uma vaga salva com empresa e descrição. Clique em Preencher formulário.
  4. Ao encontrar a etapa de apresentação compatível da Gupy, a extensão solicita um rascunho com base no currículo profissional e na vaga. Revise antes de enviar.
As respostas por IA usam um serviço externo e podem gerar cobranças. Nem toda pergunta aberta ou teste comportamental é respondido automaticamente. Informações ausentes e perguntas sobre suas preferências podem exigir sua participação. O envio final é seu.

O instalador é montado com uma lista de código e recursos permitidos. Não inclui bancos, backups, currículos, anexos, perfis de navegador, arquivos .env, chaves protegidas nem logs. O pacote acompanha um relatório com caminhos e hashes para conferência; isso é uma verificação técnica, não uma promessa de risco zero.

Os serviços escutam apenas em 127.0.0.1. Outra instalação usando as mesmas portas precisa ser encerrada antes de abrir esta. O painel não deve reutilizar os dados de uma instalação diferente.

As dependências são baixadas pelo npm. Os binários públicos do PostgreSQL vêm no instalador, obtidos da EDB e verificados por hash durante o empacotamento; nenhum banco acompanha esses binários. O aplicativo consulta sites de vagas; IA e email dependem da configuração. Distribua somente o instalador e o relatório público, nunca a pasta de uso.

O desinstalador preserva seus dados por padrão. A exclusão do banco, anexos e credenciais exige selecionar a opção de excluir dados e confirmar. O instalador não transfere perfis de outras máquinas automaticamente.

Quando algo não funcionar

Mensagem ou situaçãoO que fazer
Banco privado não iniciouConfira postgresql.log nos registros locais, a permissão da pasta e o Visual C++ x64. Reinstale preservando dados se faltarem binários.
Porta 3000, 3333 ou 55432 ocupadaEncerre a outra instalação ou serviço que usa a porta. Não aponte esta instalação para o banco de outra pessoa.
Falha ao baixar dependênciasConfira a conexão e Node.js 22+. Execute o instalador novamente; as configurações locais são preservadas.
Requisito ausente ou WinGet indisponívelOs requisitos ausentes são preparados automaticamente ao instalar. Se necessário, atualize o Instalador de Aplicativo da Microsoft Store ou utilize os links oficiais acima.
Chave inválida ou erro 401Confira a chave na plataforma Claude, salve novamente no painel e reinicie os serviços.
Sem créditos, limite ou modelo indisponívelConfira cobrança e limites na plataforma. O aplicativo mostra o erro; a disponibilidade também depende do provedor.
Extensão sem currículo ou permissãoSalve o currículo, use o mesmo perfil do Chrome, recarregue a extensão e abra a vaga pelo Job Tracker.
Campo não preenchidoConfira se o dado está salvo e complete manualmente o que faltar. Páginas diferentes podem precisar de ajustes de compatibilidade.

Use Abrir registros dos serviços para diagnosticar falhas. Logs podem conter dados do seu uso: revise e oculte informações pessoais antes de enviá-los a alguém.

Desinstale com a escolha dos dados

  1. Feche o painel. Abra Desinstalar Job Tracker.exe na pasta escolhida, use o atalho do menu Iniciar ou procure Job Tracker em Aplicativos instalados do Windows.
  2. Para manter currículo, banco, anexos, configurações e chave protegida, deixe desmarcada a opção Excluir também meus dados. Uma reinstalação na mesma pasta poderá reaproveitá-los.
  3. Para remover também esses dados, selecione a opção e confirme. O banco privado será encerrado antes da exclusão permanente de sua pasta.
  4. Clique em Desinstalar e acompanhe a conferência dos arquivos. Itens em uso são verificados novamente por até 20 segundos. A janela fecha assim que a remoção é confirmada; se houver pendências, fica aberta com o motivo. Dados preservados e arquivos desconhecidos podem permanecer na pasta. Depois, remova a extensão em chrome://extensions.

O desinstalador remove os serviços e arquivos conhecidos desta instalação. Arquivos desconhecidos e requisitos compartilhados são mantidos. Bancos de outras instalações não são apagados. A extensão permanece sob o controle do Chrome.
